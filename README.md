# Overview
This is a weather application that provides real-time and forecasted weather data specifically for Chicago, Illinois. It was developed in Java using JavaFX for the user interface and fetches weather data from the National Weather Sercies's public API.
The goal of this project was to build an app that utilizes multiple scenes on an interactive front end which also integrates external APIs.

# Home Screen (Current Weather in Chicago)
Home screen presents real-time weather data for Chicago and include:
* Weather icon (visual representation of current conditions)
* Current temperature (°F)
* Precipitation chance
* Wind speed and direction
* Short and detailed weather condition descriptions
